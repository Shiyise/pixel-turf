核心数据流 · 一局结算回路（任意场所通用，v12 加出千/事件）

进场所→ rollEvent("pre") 赌前事件→ 下注 / 开赛→ useCheat 出千判定（可选）→ 扣注 addCoins(-bet)→ 比赛 / 牌局进行→ 结算 赢则 addCoins(奖金)→ businessTick 产业分红→ advanceClock 推夜钟→ rollEvent("post") 赌后事件→ claimBailout 统一救助 G200→ gsSave 存档

出千道具数据流 · 购买 → 使用 → 效果 / 被抓

黑市购买 addCheat(id,+1)→ 场所触发 useCheat(id,mode)→ addCheat(id,-1) 消耗→ 未被抓：效果生效→ 被抓 caught：罚款 + wanted+1→ 有 pardon：罚款减半/不没收→ wanted ≥3：blackout 封杀

破产救助数据流 · v13（统一各场所旧自动救助）

coins < MIN_BET(G100)→ 地图 renderBailoutBar 弹红条→ claimBailout：+G200 / bailouts+1→ bailouts=3：按钮禁用→ giveUpNight 两段确认→ startNewNight：G1000/18:00/bailouts=0

夜结算数据流 · v14（endNight → 结局/成就 → 遗产 → startNewNight）

时钟到 05:00 / 功成身退→ endNight：runEnded=true→ judgeEnding：按夜统计/救助/产业定结局→ recordEnding：写结局图鉴（集齐解 end_all）→ unlockAch：通关/峰值/图鉴类成就→ showNightResult：称号+新成就+遗产三按钮→ chooseLegacy：cash/item/asset（可不选）→ startNewNight：应用遗产，G1000/18:00/统计清零
