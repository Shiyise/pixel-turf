# PIXEL TURF · 像素赌场

一个纯前端像素风赌场小游戏，包含七个金币互通的场所：**赛马场**、**德州扑克室**、**21 点**、**足球赌球**、**暗巷黑市**（出千道具）、**博饼坊**（六骰博状元）与地图随机街头事件；身家涨上去后还能在地图上**买生意收分红**、解锁 **VIP 贵宾厅**打万元赌局。所有玩法包在**一夜通关**的目标循环里：从 18:00 到次日 05:00 前把起始的 G1,000 滚到 **G100,000** 即获胜——正常对赌很难达标，出千道具、赛马内幕、球队贿赂和赌后事件正是为你准备的。

无后端、无构建、无依赖，双击 `index.html` 即可在浏览器游玩，进度通过 localStorage 保存。

## 玩法

### 赛马场 RACE
- 8 匹赛马上场，选马下注，按赔率结算
- 12 匹真实赛马史上的名马（秘书处、大震撼、范高尔、金枪六十等），押中冠军解锁图鉴
- **马厩养成**：赛后签约冠军马，训练速度 / 耐力 / 爆发 / 稳定四项属性
- **卖马回血**：马厩中可出售任意马匹，估价 = 签约价 6 折 + 训练投入半价 + 每级 G30（两段确认防误卖）
- **配种**：两匹马生下小马，属性取父母均值并带随机波动
- **疲劳系统**：连续参赛属性下降，需要轮换休息
- **杯赛**：G300 报名费，对手更强，冠军奖金 G3000

### 扑克室 POKER
- 德州扑克，你对战 3 个 AI，小盲 10 / 大盲 20
- 完整四轮下注（翻牌前 / 翻牌 / 转牌 / 河牌），支持边池分层结算
- 支持弃牌、跟注、加注（最小加注 / 锅底 / 全押）
- 完整牌型判定（高牌 ~ 同花顺，7 选 5 最优组合）
- AI 基于手牌强度与底池赔率决策，带少量诈唬
- **SNG 锦标赛**：G500 报名、每人 T$1500 筹码，盲注每 8 手上涨，淘汰至冠军，前两名分奖（冠军 T$1500 / 亚军 T$500）

### 21 点 BLACKJACK
- 高注码专桌：筹码 100 / 500 / 1000 / 5000，可 **ALL-IN 押上全部身家**
- 4 副牌靴，A 自动按 1 / 11 取最优点数，庄家 17 点停牌
- HIT 要牌 / STAND 停牌 / DOUBLE 加倍（仅两张牌时）
- 自然黑杰克（A + 10）赔 **3:2**，普通赢赔 1:1，和局退本

### 赌球 GOAL
- 五大联赛 20 支豪门（英超 / 西甲 / 意甲 / 德甲 / 法甲各 4 支），每轮随机抽 8 队踢 4 场，看完可刷新下一轮
- **球队强弱按现实梯度评级**（S / A / B / C 徽章，如曼城 S、拜仁 S、阿森纳 A、门兴 C），评级进入 Poisson 进球模型影响胜率与赔率
- 三种盘口：**胜平负（1X2）**、**大小球 2.5**、**精确比分**（冷门比分赔率超 10 倍）
- 赔率由 Poisson 进球模型实时计算（含 12% 庄家水位）
- **贿赂三档**：确认下注前可选 塞小费（+25% 命中）/ 买通主裁（+60%）/ 买通全队（必中），成本 = 下注额比例（下限 G300），**败露则本场作废、罚 G1,000 并本轮禁赛**；命中后按你盘口强制重采样比分
- 下注后播放 11v11（4-4-2 阵型）像素比赛直播（Canvas 动画），进球有 GOAL 闪光，按最终比分结算
- 直播中途切走再回来，比赛时钟无缝继续

### 暗巷黑市 BLACK MARKET
- 地图第七张卡进入，出售五种**出千道具**，购买后回到对应场所使用，本夜有效、新一夜清空：

| 道具 | 价格 | 效果 | 被抓率 |
|---|---|---|---|
| 底牌透视镜 | G800 | 扑克开局后自动亮明全部对手底牌（本场） | 15% |
| 换牌器 | G600 | 21 点发牌后把一张手牌换掉（自动换最小的一张） | 20% |
| 兴奋剂 | G1,000 | 赛马本场自家马速度与爆发 +30% | 25% |
| 灌铅骰子 | G500 | 博饼本局 4 点概率翻倍（温和灌铅） | 20% |
| 免罪金牌 | G3,000 | 被抓时豁免：罚款减半、其余道具不没收 | 0 |

- **被抓**：罚款普通厅 G2,000 / VIP 厅 G20,000（付不起直接进局子结束一夜），通缉 +1
- **通缉满 3 次**：黑市当夜封杀，买不到任何道具（新一夜清零）

### 博饼坊 BOBING
- 地图第八张卡进入：六粒骰子掷一次定奖，一局 5 分钟
- 九档奖项：一秀 1x / 二举 1.2x / 四进 1.5x / 三红 2.5x / 对堂 4x / 状元 10x / 状元插金花 30x / 罚黑输注
- 普通桌注码 100 / 500 / 1000；VIP 桌（解锁后）5,000 / 10,000
- 可用**灌铅骰子**让本局 4 点概率翻倍（普通桌期望仍为负，VIP 大注才有赚头）

### 随机事件
- 进入任一赌博场所（赌前）与每次结算后（赌后）各有 18% 概率触发街头事件
- **富婆**：给赏钱 / 让你猜硬币（赌运气）；**黑道**：收保护费 / 递烟套近乎；另有 醉汉、小偷、老赌棍、高利贷（借 G1,500，之后 3 局每局扣 G300）、发牌员、停电、算命先生、记者、捡钱包、粥摊、保安查房（没收一件出千道具）、火并、后屋牌局（耗时 10 分钟）等
- 事件金额按玩家当前身家比例缩放，有钱时富婆更大方、黑道收更多

四个场所金币互通，输光或低于最低注码可在地图领救助金（每夜 3 次），也可随时放弃今夜重开。

|---|---|---|

| 赛马场股份 | G25,000 | G600 |
| 扑克室 | G80,000 | G2,000 |
| 博彩公司 | G200,000 | G5,000 |

## VIP 贵宾厅 VIP LOUNGE

- 一夜内持有金币达到 **G50,000** 即解锁（当夜有效），地图第五张卡片进入；开始新的一夜后重新锁定，需再次达标
- **VIP 黑杰克**：筹码 5,000 / 10,000 / 50,000 / 100,000，规则与普通桌一致，照样 ALL-IN
- **VIP 德州现金桌**：盲注 200 / 400，三个 AI 各带 G50,000 上桌（至少带 G4,000 才能入座）
- **VIP SNG 锦标赛**：G5,000 报名、每人 T$15,000，盲注为普通 SNG 的 10 倍，冠军 G15,000 / 亚军 G5,000
- VIP 厅与普通厅共用一个钱包；VIP 桌不发救助金，输光回普通扑克现金桌领救助金东山再起

## 一夜通关 NIGHT RUN

游戏以"一夜"为一局循环：时钟从 **18:00** 走到次日 **05:00**（共 11 小时 / 660 分钟），**在天亮前把 G1,000 起始资金滚到 G100,000 即通关**；到点仍未达标则这一夜失败。

- 地图顶部"今晚目标"面板实时显示夜钟、目标进度条与距天亮时间；各场所顶栏也有夜钟
- **每完成一局赌博消耗时间**，剩余时间不足以打完一局时无法开局：

| 场所（一局） | 耗时 |
|---|---|
| 21 点 | 5 分钟 |
| 德州扑克（现金 / SNG，每手） | 10 分钟 |
| 赛马（普通 / 杯赛） | 20 / 30 分钟 |
| 足球赌球 | 45 分钟 |
| 博饼（一掷） | 5 分钟 |

- 训练、配种、买卖生意不耗时
- **破产救助**：金币低于最低注码 G100 时，地图自动弹出红色"身无分文"救助条，可领 G200 救助金继续，**每夜最多 3 次**；次数用完或不想再耗，可直接在目标面板点"放弃今夜 · 重新开始"（两段确认），任何卡死状态都能从这里脱身
- 金币达到 G100,000 后，地图面板"功成身退"按钮亮起，可提前锁定通关，不必硬撑到 05:00
- **开始新的一夜**：金币重置为 G1,000、清空已购产业与 VIP 解锁状态、时钟回到 18:00；**马厩、名马图鉴、累计通关次数与历史最高身家会保留**。纯运气玩法期望为负，前期多靠扑克启动，养出强马之后才有望一夜十万

## 运行

直接用浏览器打开 `index.html` 即可。

## 文件结构

| 文件 | 说明 |
|---|---|
| `index.html` | 页面结构与像素风样式（唯一入口） |
| `shared.js` | 共享钱包、存档、地图界面、置业分红、VIP 解锁与随机事件调度 |
| `race.js` | 赛马玩法模块（含马经传闻 / 兴奋剂） |
| `poker.js` | 德州扑克模块（现金桌 + SNG 锦标赛 + 底牌透视镜） |
| `blackjack.js` | 21 点模块（含换牌器） |
| `football.js` | 足球赌球模块（1X2 / 大小球 / 精确比分 + 评级档位 + 贿赂） |
| `cheat.js` | 暗巷黑市：出千道具购买 / 使用 / 被抓 / 通缉封杀 |
| `events.js` | 随机事件库与弹窗（富婆 / 黑道 / 高利贷等） |
| `bobing.js` | 博饼坊：六骰博状元 + 灌铅骰子 |

> 十个文件必须放在同一目录下。
